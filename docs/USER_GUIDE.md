# Краткая инструкция для Сони

Бот — личный рабочий инструмент Сони. Доступ к командам ограничен Telegram ID из `ADMIN_ID` в `.env`; репетиторы и ученики в боте не регистрируются и не авторизуются.

## Создать передачу вручную

1. Открой бота и нажми **➕ Новая передача**.
2. Выбери существующую заявку либо **✍️ Ввести данные вручную**. Если активных заявок ещё нет, ручной ввод начнётся сразу.
3. Введи имя репетитора, его предмет (или пропусти), имя ученика, контакт (или пропусти), источник заявки и предмет/запрос ученика (или пропусти).
4. Заполни, кто передал ученика, ставку занятия, условия комиссии и срок оплаты. Процентная комиссия рассчитывается с заработка за проведённые платные занятия.
5. Проверь сводку и нажми **✅ Подтвердить**. До подтверждения записи в базе не создаются.

При подтверждении бот ищет активные записи ученика, репетитора и источника по имени без учёта регистра и крайних пробелов. Найденные записи используются повторно; отсутствующие добавляются. Контакт существующего ученика не перезаписывается введённым значением. Заявка с тем же учеником, источником и предметом тоже используется повторно, если она не потеряна; иначе создаётся новая. Затем создаётся передача и журналируется переход заявки в статус «передана». Операция выполняется одной транзакцией: при ошибке новые записи откатываются вместе.

Для нескольких учеников с одинаковым именем лучше добавлять различимый контакт в карточке ученика отдельно и поддерживать уникальные понятные имена. Автоматическое сопоставление использует именно имя, а не телефон.

## Остальные действия

Главное меню также позволяет вести карточки учеников/репетиторов, заявки, занятия, оплаты, возвраты, корректировки комиссий, задолженности, аналитику и ручную синхронизацию Google Sheets. Перед ручной синхронизацией проверь `GOOGLE_SHEETS_ID` и используй только нужную таблицу. Автоматическая синхронизация включается отдельно настройкой проекта.

## Локальный запуск

Следуй разделам Local setup и Disposable PostgreSQL в корневом [README](../README.md). Не применяй миграции к существующей базе, пока не проверена её резервная копия и целевая среда. Не помещай `.env`, ключ service account, дампы базы и локальные данные в Git.
